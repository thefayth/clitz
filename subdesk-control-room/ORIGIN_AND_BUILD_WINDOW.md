# Origin and OpenAI Build Week build window

## Pre-existing foundation

Before the July 13–21, 2026 contest window, the private CLITZ workspace contained broader experiments involving creator media operations, Subdesk capture, local review queues, DICKZ safety concepts, WordPress plugins, and community rooms. Those systems are not being submitted as if they were newly created.

## Meaningful contest extension

This standalone project was initialized and implemented on July 21, 2026 specifically for OpenAI Build Week. New contest work includes:

- a separate Sites/Vinext application and repository;
- a family-safe, general-purpose creator workflow;
- live GPT‑5.6 Responses API integration with strict structured output;
- a raw-input-minimizing D1 data model;
- editable multi-channel drafts and an explicit human approval gate;
- provenance receipts and Markdown/JSON exports;
- responsive, keyboard-friendly public UI;
- contest-specific README, tests, deployment packaging, demo script, and Canva pitch plan.

The source CLITZ projects remain intact. This repository contains only the standalone contest product and the evidence needed to distinguish new work from earlier concepts.
